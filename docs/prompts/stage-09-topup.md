# Этап 09: пополнение

Работаешь в `D:\Projects\hostwatch`.

## Прочитай

1. `docs/research.md` целиком, особенно разделы про пополнение у каждого хостера и «ЮKassa: как получить ссылку СБП».
2. `docs/spec.md`: сценарий «Баланс → Пополнить», решения 5 и 6.

## Сделай

1. `core/payments/yookassa.py`: из `confirmation_url` получить ссылку `qr.nspk.ru` (CSRF → `sbp/start` → опрос `status` до `qrCodeData`). Общий модуль для Timeweb и Aeza.
2. `SupportsTopup` в плагинах:
   - **Aeza:** `POST /billing/invoices`. СБП → `payload.url` → ЮKassa → nspk. Крипта (`pawnow:*`) → адрес, сумма, строка QR прямо из ответа. Список сетей — из `/billing/payment-methods`.
   - **Timeweb:** сессия панели из этапа 06. `update-token` с сохранением нового `refresh_token` **до** использования access-токена; плательщик; `POST /portal/v4/invoices` с `sbp` → ЮKassa → nspk. Минимум > 100 ₽.
   - **Regxa:** `addfunds` → `cryptomus/create-payment` → ссылка Cryptomus. Адрес кошелька — через Playwright в контейнере `browser` (открыть страницу, выбрать сеть, прочитать адрес и сумму). Не вышло → отдать ссылку.
   - **AdminVPS:** `addfunds` (`paymaster_sbp`) → форма PayMaster → `cpay/<id>` → `AuthPaymentExternal` (`x-public-id`, `SBP`) → nspk. Шаг 3 из Python ещё не проверен — проверь первым.
3. Бот: способ → сеть (для крипты) → сумма (минимум хостера, «чтобы хватило до конца следующего месяца», своя) → сообщение со ссылкой, QR-картинкой (`segno`) и кнопкой «Оплатил». После «Оплатил» — перечитать баланс через 2, 5, 10 минут.
4. Ссылку СБП запрашивать в момент нажатия: оплата ЮKassa живёт ~10 минут.
5. `payments` и `journal`: каждое создание счёта.
6. Если счёт через запросы создать нельзя — ссылка на страницу пополнения хостера.

## Не делай

- Не оплачивай ничего сам. Создавать счета можно; оплачивает только владелец.

## Проверь

- По каждому хостеру и каждому способу создан счёт, ссылка открывает оплату, QR читается телефоном. Счета не оплачены, кроме одного.
- Владелец оплачивает **один** счёт на минимальную сумму. Бот видит пополнение, прогноз обновился.
- Фикстуры платёжных ответов очищены, `gitleaks` чист.

## Готово, когда

Все способы пополнения работают или честно заменены ссылкой на страницу; одно реальное пополнение прошло через бота. Строка в «Журнал этапов».
