# Этап 10: управление

Работаешь в `D:\Projects\hostwatch`.

## Прочитай

1. `docs/research.md`: питание, автопродление, продление и оплата счетов у каждого хостера.
2. `docs/spec.md`: сценарий «Подтверждения», решения 3, 4 (`journal`), 10.

## Перед началом

Спроси владельца, на каком сервере у каждого хостера можно проверять действия. Без названного сервера ничего не вызывай. Действия на живом аккаунте выполняешь только вместе с владельцем, по одному.

## Сделай

1. Общий механизм подтверждения в боте: «что, где, сколько» → «Да / Отмена», одноразовый nonce на 5 минут, повторное нажатие игнорируется. Результат и ответ хостера (без секретов) — в `journal`. Уведомление о действии с деньгами — всегда.
2. Отметка «выключено владельцем», чтобы уведомление о статусе `stopped` не приходило после своего же выключения.
3. Возможности в плагинах:
   - **Aeza:** `SupportsPower` (`ctl/restart`, `ctl/suspend`, `ctl/resume`), `SupportsAutorenew` (`PATCH autoProlong`), `SupportsRenew` (`prices` → `prolong`).
   - **Timeweb:** `SupportsPower` по официальному API (автопродление не нужно, оплата почасовая).
   - **Regxa:** `SupportsPower` (`/api/services/vps/power/...`), `SupportsPayInvoice` (`apply-credit`).
   - **AdminVPS:** `SupportsPower` (POST `modop=custom`, `a=boot|shutdown|reboot` с CSRF `token`), `SupportsAutorenew` и `SupportsRenew` через HostingRenewals. Как отправляется форма подтверждения модального окна, сначала посмотри в браузере вместе с владельцем.
4. Дедики показываются отдельно; кнопки — по тем же возможностям.
5. Журнал в боте: последние 20 записей, листание.

## Проверь

- Тесты: nonce одноразовый; без подтверждения ничего не вызывается; ответ хостера в журнале без секретов.
- На тестовом сервере каждого хостера вместе с владельцем выполнено каждое действие. Результат совпадает с кабинетом.

## Готово, когда

Все действия всех хостеров проверены на живых тестовых серверах и записаны в журнал. Строка в «Журнал этапов».
