# Этап 14: документация и релиз 1.0

Работаешь в `D:\Projects\hostwatch`.

## Прочитай

1. `docs/spec.md`: критерии успеха (фаза 1), решения 5, 15, 16, 17, раздел «Требования к коду и текстам», особенно про тексты.
2. Правила текста: https://ru.wikipedia.org/wiki/Википедия:Признаки_сгенерированности_текста.

## Сделай

1. `README.md` (английский) и `README.ru.md`: что умеет бот (таблица хостеров и возможностей), требования к серверу, установка одной командой, создание бота в BotFather, подключение хостеров, обновление, бэкап и восстановление, `HEARTBEAT_URL`, «Если сервер взломали» (где отозвать каждый ключ и сессию), почему отдельный VPS, а не VPN-нода.
2. `install.sh`: ставит Docker, если его нет; создаёт `/opt/hostwatch`; спрашивает `BOT_TOKEN`, `OWNER_ID`, необязательный домен; генерирует `HOSTWATCH_KEY` и показывает его один раз; запускает Compose. Больше в системе ничего не меняет.
3. `docs/adding-a-hoster.md`: порядок разбора кабинета (API → XHR → HTML), что записывать про каждый запрос, `hostwatch new-plugin <id>`, `record`, контрактный тест, чек-лист перед PR.
4. Команда `hostwatch new-plugin <id>` и шаблон `plugins/_template/`.
5. GitHub Actions: сборка и публикация образа в GHCR по тегу `v*`; `docker-compose.yml` использует образ из GHCR.
6. `CHANGELOG.md`, `CONTRIBUTING.md` (коротко), шаблоны issue (с напоминанием не прикладывать cookie и базу).

## Проверь

- Чистая сессия агента или знакомый владельца ставит бота на чистый VPS **только по README** и подключает Aeza по ключу. Засеки время, цель — 15 минут. Всё, где споткнулся, исправь в README.
- Тексты README прочитаны на признаки сгенерированности: нет «важно отметить», пустых вступлений, пафоса.
- Агент в чистой сессии по `adding-a-hoster.md` делает заготовку плагина для любого пятого хостера, и она проходит контрактный тест на фикстурах.
- `gitleaks` по всей истории чист.

## Готово, когда

Установка по README укладывается в 15 минут, инструкция по плагину работает. Владелец сам создаёт публичный репозиторий и ставит тег `v1.0.0`. Строка в «Журнал этапов».
