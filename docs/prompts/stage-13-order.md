# Этап 13: заказ серверов в боте

Работаешь в `D:\Projects\hostwatch`.

## Прочитай

1. `docs/research-orders.md`.
2. `docs/spec.md`: решения 5 (лимиты, второе подтверждение), 11.
3. Механизм подтверждений из этапа 10.

## Сделай

1. `SupportsOrder` в ядре: `catalog() -> Catalog` (локации, тарифы, ОС, периоды, цены), `order(OrderRequest) -> OrderResult`, при возможности `root_password(server_id)`.
2. Реализация в плагинах — по `research-orders.md`. Хостеры с пометкой «v2» не получают `SupportsOrder`.
3. Каталог кэшируется на час, перед подтверждением цена перечитывается.
4. Бот: «Заказать» → аккаунт → локация → тариф → ОС → период → итог → подтверждение. Сумма выше месячного лимита — второе подтверждение. Денег не хватает — предложить пополнение на недостающую сумму (этап 09).
5. «Заказать такой же» на карточке сервера.
6. SSH-ключ владельца в настройках; ставится при заказе, где хостер умеет.
7. «Показать пароль»: запрос у хостера, сообщение удаляется через 5 минут; пароль не хранится и не пишется в журнал и логи.
8. Журнал и уведомление о каждом заказе.

## Проверь

- Тесты: лимит, второе подтверждение, изменение цены между каталогом и подтверждением, нехватка баланса, пароль не попадает в журнал и логи.
- Владелец заказывает через бота самый дешёвый сервер у каждого поддержанного хостера и удаляет его руками.

## Готово, когда

Живой заказ прошёл у каждого поддержанного хостера. Строка в «Журнал этапов».
